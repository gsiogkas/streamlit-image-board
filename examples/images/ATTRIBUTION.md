# Demo image attribution

All JPEGs in this folder are **public domain** (U.S. government works and/or
explicitly released PD images), mirrored via
[Wikimedia Commons](https://commons.wikimedia.org/) and resized to ~320px on the
long edge for the Streamlit demo.

Refresh / re-download with:

```bash
uv run python scripts/fetch_demo_images.py
```
