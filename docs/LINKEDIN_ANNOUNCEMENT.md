# LinkedIn announcement (draft)

Just shipped **streamlit-image-board** — a snappy React image board for Streamlit (Components v2).

Select images with a click (or checkbox), open full-size URLs, hover for context, select/deselect all, and style each card’s background + font — without waiting on a full Streamlit rerun for every toggle. Board fields also load from JSON.

The selection checklist is a plain `list[str]` of ids, so it plays nicely with AgGrid (classic or v2) in the same app.

Built next to streamlit-drawable-konva, same CCv2 + Vite stack.
